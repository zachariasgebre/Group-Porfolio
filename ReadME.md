# Modern Developer Portfolio

A sleek, responsive, and interactive developer portfolio website built using pure HTML5, CSS3, and Vanilla JavaScript. Designed to showcase projects, technical skills, background experience, and provide a functional contact interface.

---

## 🌟 Features

- Responsive & Mobile-Ready: Includes a responsive layout with a slide-out drawer menu for mobile and tablet screens.
- Multipage & Modular: Comes with modular HTML pages (index.html, about.html, skills.html, projects.html, contact.html).
- Interactive Project Modal: Clicking "View Details" opens an interactive modal overlay rendering custom project descriptions dynamically via JavaScript.
- Category Filtering: Filter project cards dynamically by technology category (JavaScript, HTML/CSS, Other).
- Working Contact Form: Formspree integration for direct email delivery to your inbox without requiring a backend server.
- PDF CV Download: Direct attachment download link for your resume.
- Dynamic Footer: Automatically updates the copyright year using JavaScript Date().

---

## 🛠 Tech Stack

- Frontend: HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (ES6+)
- Icons & Typography: [Font Awesome 6](https://fontawesome.com/), [Google Fonts (Inter)](https://fonts.google.com/)
- Form Service: [Formspree](https://formspree.io/)
